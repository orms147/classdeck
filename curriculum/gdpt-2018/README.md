# gdpt-2018

Curriculum data for English, grades 3–5, from *Chương trình giáo dục phổ thông 2018* (Thông tư 32/2018/TT-BGDĐT, English language programme, and amendments), transcribed as versioned YAML. Format and ID policy: [docs/curriculum-config.md](../../docs/curriculum-config.md).

```
tieng-anh/lop-3.yaml     grade 3
tieng-anh/lop-4.yaml     grade 4
tieng-anh/lop-5.yaml     grade 5
```

All three files are `status: seed`: the structure is complete (five units each, cumulative word lists, classroom language, grammar-scope regexes, phonics) but the outcome wording has not been checked line by line against the official programme. Only outcome statements, word lists, pattern templates and unit *numbers and titles* are stored here. No textbook content.
